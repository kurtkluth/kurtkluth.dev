## 2026-10-04

Added Reelabel to the portfolio and documentation hub. The documentation covers
the current private development preview: provider credentials and automatic
import lookup, saved movie/TV naming profiles, encoding presets and test clips,
tagged copies, and restart recovery.

This is a documentation milestone, not a public binary release. Versioned
public releases, an installer, signing, and automatic updates are not available.
