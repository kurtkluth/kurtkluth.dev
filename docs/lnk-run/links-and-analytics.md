## Manage links

Use search, the **Active** and **Expired** tabs, sorting, and tag filters to find links. A link's actions let you edit, copy, inspect analytics, download a QR code, or delete it. Avoid changing a slug that has already been shared. Deleting a link stops its short URL from working. To restore an expired link, edit its expiration.

## Understand traffic

**Analysis** provides aggregate counters, charts, and filters. Open a link's analytics from its actions for a narrower view. **Realtime** polls approximately every 10 seconds and gradually replays events; it is not a continuous live stream. Cloudflare Analytics Engine can sample results, so counts may be approximate.

Under **Import/Export**, choose **Export Access Data** to download CSV data for a date range and optional slug. Analytics may include IP addresses, user agents, referrer domains, and approximate location. Treat dashboard access and exports as sensitive and consult the [privacy policy](https://lnk.run/privacy).

Link JSON exports and R2 snapshots do not include analytics.
