## Sign in

Open [lnk.run](https://lnk.run/) and enter the authorized site token when prompted. This token is a Worker secret, not a GitHub password or Cloudflare API token. Use a trusted device: the browser stores the token in local storage until you sign out or clear it. The preview environment uses a different token.

## Create a link

1. Open **Links** and choose **Create Link**.
2. Enter the full destination URL, including `https://` or `http://`.
3. Enter a custom slug or generate one. The slug becomes the last part of the short URL. The paths `dashboard` and `privacy` are reserved.
4. Optionally configure tags, expiration, password protection, routing, UTM parameters, or social preview details, then save.
5. Copy the short URL and test it in a private browser window before sharing it. Check any password, expiration, and routing rules separately.

Use the sidebar account menu to sign out. See [Links and Analytics](./links-and-analytics.md) for managing links after creation.
