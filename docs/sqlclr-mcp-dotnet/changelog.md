## 2026-09-28 - Database architect preview

- Added deterministic catalog review, bounded aggregate profiling, and
  selected entity-pair analysis to the development branch.
- Added optional Jev judgments behind server configuration and per-call
  opt-in, with User Secrets support for local credentials.
- Added a provisional labeled evaluation harness. The first results do not
  support an automatic semantic review threshold.
- Added this project and its documentation to kurtkluth.dev as a featured
  application. Site publication follows the application pull requests.

For detailed code history and current release status, see the
[GitHub repository](https://github.com/kurtkluth/sqlclr-mcp-dotnet) and its
[pull requests](https://github.com/kurtkluth/sqlclr-mcp-dotnet/pulls).
