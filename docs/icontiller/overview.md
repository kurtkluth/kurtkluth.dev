IconTiller is **App Layout Editor by Kurt Kluth**, a Windows desktop app for
arranging iPhone Home Screens with your mouse and a larger screen. Read the
layout and real app artwork over USB, make a local draft, then review and
apply a supported change.

**Development preview.** Compatibility has been tested on one connected
phone reporting iOS 27.0. Broader device and iOS support is not established.

## What it does

- Insert an app between tiles and shift intervening entries across pages.
- Swap two apps, including an exchange between a page and an existing folder.
- Search apps and folders, inspect folder pages, and undo or redo local edits.
- Save drafts and reopen them later without overwriting existing files.
- Review affected positions before Apply, save a fresh backup, and independently
  read back the full layout to check the result.

Page reorders preserve existing page sizes and the dock. Creating or renaming
folders and adding pages are **local draft edits only**. App Library removal,
dock changes, widget editing, and full-layout restoration are not enabled.
Hidden-page visibility is not preserved; pages may become visible after Apply.
