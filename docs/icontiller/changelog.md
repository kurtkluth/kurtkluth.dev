## 2026-09-12: Development-preview documentation

Added IconTiller to the portfolio and documentation hub with Windows setup,
editing and Apply instructions, troubleshooting, and a privacy and limitations
FAQ. This entry records the documented baseline, not a numbered binary release.

The preview includes USB layout reads, real app artwork, insert-and-shift
editing, app swaps, search, undo/redo, and saved drafts. Supported Apply
operations preserve page sizes and the dock, save a fresh backup, and compare
an independent full read-back. Folder creation, renaming, and added pages
remain draft-only; App Library removal and full-layout restoration are not enabled.

Compatibility testing is limited to one phone reporting iOS 27.0. See the
[source repository](https://github.com/kurtkluth/IconTiller) for current code
and the [overview](./overview.md) for the user guide.
